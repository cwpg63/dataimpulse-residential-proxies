## 真正让人踩坑的是定位附加费

$1/GB 是标价，不是所有场景下的实际单价。

国家/地区定位包含在基础单价里，不额外收钱。但州、城市、邮编、ASN 这四级更精细的定位，在住宅代理上是要加钱的——第三方分析站 AIMultiple 的记录是**按标准费率的 2 倍计算**。也就是说，你的抓取任务如果需要精确到城市，账单上的实际成本会直接翻倍，而不是 $1/GB。

同一条规则在数据中心代理上，官方产品页把州/城市/邮编/ASN 列成了包含项。两个说法对不上，AIMultiple 自己也提醒"下单前跟客服确认"。这一条是本文里唯一建议你动手问一句再掏钱的地方。

反过来，如果你只按国家定位，那 $1/GB 就是实价，没有隐藏项。多数电商比价、SERP 抓取、广告验证类任务，国家级定位够用。

## "流量永不过期"具体怎么运作

这部分值得单独讲，因为它影响的是长期成本，而不是单价。

你买的 GB 存在账户余额里，用的时候往下扣，不按任何日历周期重置。今天买 50GB，这周跑掉 10GB，剩下 40GB 放到三个月后用，还是原样在账上。没有月末清零，没有超量阶梯涨价，也没有"公平使用政策"偷偷限速。

对用量起伏大的项目，这个模式的实际成本比订阅制低不少——订阅制里没用完的额度是直接消失的。反过来，如果你每月稳定跑满一个固定量级，订阅制大包的单价通常更低。这是一道算术题，不是立场题。

顺带一提，你基本能预判账单：充多少钱就是多少额度，不存在忘记取消订阅被扣一个月这种事，因为它压根没有订阅。

## 从注册到跑通第一条请求

流程比我预想的短。没有企业资质审核（KYC），从注册到代理能用大概几分钟。

1. **注册账号**：邮箱或社交账号登录都行，不需要提交营业执照。这跟 Oxylabs、Bright Data 那种要求企业验证的 3–7 天试用完全不是一回事。
2. **充值入门档**：最低 $5。新用户建议先拿住宅的 5GB 试，够把集成写完并测出真实成功率。
3. **在仪表盘生成代理列表**：选国家、选轮换方式（每次请求换 IP，或保持一个会话）、选协议、选输出格式，列表立刻出来。旁边的 cURL 命令会跟着设置实时更新，可以不走终端先验证一下连通性。
4. **接进你的爬虫**：网关地址是 `gw.dataimpulse.com`。HTTP/HTTPS 轮换走 823 端口，SOCKS5 轮换走 824 端口。协议上 HTTP(S) 和 SOCKS5 都支持。
5. **需要固定 IP 就用粘性会话**：粘性端口在 10000–20000 之间，单次会话默认 30 分钟，最长可以设到 120 分钟。轮换模式适合高并发抓取，粘性模式适合需要连续登录状态的场景。

国家定位的写法是在用户名里加后缀，比如 `YOUR_LOGIN__cr.us:YOUR_PASSWORD@gw.dataimpulse.com:823` 就是指定美国出口。认证方式除了用户名密码，也支持 IP 白名单。

并发方面，官方 FAQ 给的数字是最多 2000 个并发连接线程，需要更高可以申请提升。这个量级对中小型项目够用，超大规模抓取就得提前跟客服谈。

## 第三方测试跑出来是什么水平

厂商公布的 99.51% 成功率不能当独立结论看。能查到的第三方数据有两组，而且对不上，这本身就是个有用的信息：

**ProxyStats 的 30 天自动监测**（共 37,871 次测试）给出的结果是可用率 93.7%，24 小时成功率 93.5%、7 天 93.6%，中位延迟 530 毫秒，P95 延迟 1600 毫秒。它把 DataImpulse 在 P50 延迟、P95 延迟、Google 成功率和通用网页抓取成功率四项上都归进了前 20%。

## 该买和不该买的三种情况

**适合：**
- 用量不稳定，或者还在测试阶段，不想被月费绑住
- 目标站点用住宅 IP 就能过，不需要城市级精度
- 抓取量中等、偶尔要跑一次的团队——买一次流量放着，下个月想起来还能用
- 需要移动 IP 做 App 或移动端页面测试，但用量不大

**不太适合：**
- 需要**静态 ISP 代理**，长期绑同一个 IP 做账号运营
- 想要**全托管爬虫 API**，希望对方把反爬、渲染、解析全包掉
- 要访问银行、政府这类高风控站点——官方自己也明确说不是为此设计的
- 每月稳定跑满大额流量，且需要固定端点——这种情况按 IP 包月的方案可能更省
